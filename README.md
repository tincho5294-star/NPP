# NPP

이 게임은 **Pressurized Water Reactor 제어를 기반으로 한 하드코어 통제 게임으로, 안전하게 운전하는 대신 위험하고 복잡하게 운전할수록 점수가 올라가는 구조를 가진다. 플레이어의 **스타일이 곧 정신력**이며, 여러 계통을 적극적으로 다루고 아슬아슬한 상태를 유지할수록 정신력이 유지·상승한다. 반대로 소극적이고 안정적인 운전은 정신력을 감소시키며, 감소한 정신력은 쉽게 회복되지 않는다. 즉, 현실의 ‘안전 우선’ 원칙을 뒤집어, 위험을 감수하고 통제하는 플레이 자체가 핵심 재미가 되는 컨셉이다.
